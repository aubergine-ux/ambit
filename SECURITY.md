# Security

If you find a vulnerability, please report it privately through GitHub's
[private vulnerability reporting](https://github.com/aubergine-ux/ambit/security/advisories/new)
rather than in a public issue. Include the Ambit version, the Android version and steps to
reproduce.

Things that count as security issues here:

- Anything that makes Ambit send data off the device.
- Ways to read Ambit's database, backups or exports without the user's key, password or PIN.
- Ways for a tracker owner to learn that Ambit has detected their tracker, beyond the one
  Play sound connection the user confirms.
- Detection bypasses: a tracker format that follows someone without Ambit noticing.
